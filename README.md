# Interact2Hack 2027 · Propuesta para auspiciantes

Presentación web para auspiciantes y partners de Interact2Hack 2027, el hackathon de la Universidad San Francisco de Quito (19 al 21 de febrero de 2027).

**Ver en línea:** https://aparrauio.github.io/i2h-sponsors-2027/

## Uso
- Flechas, barra espaciadora o deslizar para avanzar.
- `F` pantalla completa · `N` guion del presentador.
- En la última slide, el botón «Comparte esta propuesta» permite enviar el enlace, copiarlo o guardar la presentación como PDF.
- `#N` al final de la URL abre directamente la slide N (por ejemplo `#19`).

## Estructura
- `index.html`: la presentación completa (estilos y scripts incluidos).
- `assets/`: fotos, fuentes, logos, imagen de vista previa para redes e íconos.
